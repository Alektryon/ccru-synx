# ccru-synx
Synx Gematria calculator that uses the full text of "Ccru Writings 1997-2003" as its database.<br>
<br>
The "Synx" Gematria system makes a direct correspondence between the 36 alphanumeric digits [0-9]+[A-Z] and the 36 divisors of 1260, the smallest natural number having exactly 36 divisors.<br>
<br>
Based on [Vanessa Kindell](https://github.com/vanessakindell)'s [Secret Cipher](https://github.com/vanessakindell/secret-cipher) calculator.
